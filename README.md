# E-commerce Product Recommender

## Fichiers
- `amazon_produits.ipynb` : notebook propre du projet
- `app.py` : application Streamlit complète
- `requirements.txt` : dépendances Python

## Dataset 
Fichier Kaggle 'electronics_filtered.csv'.

## Étapes
1. Installer les dépendances :
   `pip install -r requirements.txt`

2. Ouvrir le notebook et l'exécuter :
   `amazon_produits.ipynb`

3. Le notebook génère :
   `electronics_filtered.csv`

4. Lancer l'application Streamlit :
   `streamlit run app.py`

## Remarque
L'application Streamlit lit `electronics_filtered.csv`. Il faut donc exécuter le notebook au moins une fois avant.
